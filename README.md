# Демо fastify production-ready

## Команды

### `npm start`

Запускает сервер, если запускается с `NODE_ENV=production`, то запускает его в production режиме,
иначе логирование устанавливается в уровень debug, включается watch-режим и
поднимается debug-сервер на порту 9229.

### `npm test`

Запускает тесты, но тестов пока нет.)
