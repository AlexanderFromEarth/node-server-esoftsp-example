# Директория путей

Маршруты определяют пути в вашем приложении.
Структура Fastify поддерживает модульный монолитный подход, где ваше приложение
организовано в отдельные автономные модули.
Это облегчает масштабирование и будущий переход к микросервисной архитектуре.
В будущем вы, возможно, захотите самостоятельно развернуть некоторые из них.

В этой папке вы должны определить все маршруты, которые определяют конечные точки
вашего веб-приложения. Каждый сервис является [плагином](https://fastify.dev/docs/latest/Reference/Plugins/), он
инкапсулирован (он может иметь свои собственные независимые плагины) и обычно хранится в файле; будьте осторожны,
чтобы логически группировать свои маршруты, например, все маршруты `/users` в файле `users.ts`.

Если один файл становится слишком большим, создайте папку и добавьте туда файл `index.ts`:
этот файл должен быть плагином, и он будет автоматически загружен приложением.
Теперь вы можете добавить столько файлов, сколько захотите, в эту папку.
Таким образом, вы можете создавать сложные маршруты в пределах одного монолита
и в конечном итоге извлекать их.

Если вам нужно поделиться функциональностью между маршрутами,
поместите эту функциональность в папку плагинов и зашерьте её через
[декораторы](https://fastify.dev/docs/latest/Reference/Decorators/).

Если вы немного запутались в использовании `async/await` для написания маршрутов,
вам лучше взглянуть на [Promise resolution](https://fastify.dev/docs/latest/Reference/Routes/#promise-resolution)
для получения более подробной информации.
