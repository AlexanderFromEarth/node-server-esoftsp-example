# Директория плагинов

Плагины определяют поведение, которое является общим для всех маршрутов
в вашем приложении. Аутентификация, кэширование, шаблоны и все остальные
сквозные задачи должны решаться плагинами, размещенными в этой директории.

Файлы в этой директории обычно объявляются через модуль
[`fastify-plugin`](https://github.com/fastify/fastify-plugin),
делая их не инкапсулированными (не создают новый контекст).
Они могут определять декораторы и устанавливать хуки, которые
будет в последствии использованы во всем приложении.

Загляните:

* [Автостопом по плагинам](https://fastify.dev/docs/latest/Guides/Plugins-Guide/)
* [Декораторы](https://fastify.dev/docs/latest/Reference/Decorators/).
* [Жизненный цикл](https://fastify.dev/docs/latest/Reference/Lifecycle/).
